# Ethra Canon Roster — curated skeleton

**Doctrine:** this file is the *curated skeleton* of the canon reference — adjudicated
identities only. Derived stats (mention counts, first appearances, arc coverage) are
computed by `python canon/compile_canon.py` into `ledger-derived.md` and are never
hand-written here. This skeleton changes **only at canonization events** (Ainz rulings).
If the story evolves, the ledger regrows; this file changes only when a decision is made.

**Format:** one table row per entity. Aliases separated by `;`. Status values:
`alive | dead | missing | excised | renamed | nonperson | adjudication-pending`.
